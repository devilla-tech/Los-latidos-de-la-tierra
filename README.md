# Los-latidos-de-la-tierra
🚀 Los Latidos de la Tierra es un proyecto inclusivo desarrollado para el NASA Space Apps Challenge. Está dirigido especialmente a personas con discapacidad visual y busca acercarlas a la exploración del espacio mediante sonidos ambientales y experiencias auditivas, demostrando que el universo también se puede descubrir a través del sonido.
